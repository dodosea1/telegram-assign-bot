설치 (처음 한 번)

와이파이를 켜고 순서대로 하세요. 끝낸 단계는 체크해 두면 이 폰에 기억됩니다.

  1. F-Droid 설치

    • 폰 인터넷에서 f-droid.org 접속 → F-Droid 다운로드
    • ‘출처를 알 수 없는 앱’ 안내가 나오면 설정 → 허용 → 설치

  2. Termux 앱 두 개 설치

    • F-Droid 에서 🔍 termux 검색
    • Termux 설치, Termux:Widget 설치
    플레이 스토어의 Termux 와 섞어 깔면 홈 화면 버튼이 작동하지 않습니다. 두 개 모두 F-Droid 에서 받으세요.

  3. 배터리 · 권한 설정

    • 폰 설정 → 애플리케이션 → Termux → 배터리 → 제한 없음
    • 같은 화면에서 다른 앱 위에 표시 → 허용

    안 하면 폰이 절전하면서 자동응답을 꺼 버릴 수 있습니다.

  4. API 키 받기

    • my.telegram.org 접속 → 전화번호(+8210…) → 텔레그램 앱으로 온 코드 입력
    • API development tools → App title · Short name 에 아무 영어 이름 → Create application
    • 나온 api_id(숫자)와 api_hash 를 메모
    api_id · api_hash 는 내 계정 열쇠입니다. 누구에게도 보여 주지 마세요.

  5. 설치 명령 붙여넣기

    아래 복사 → Termux 열기 → 검은 화면 길게 누르기 → Paste → 엔터

    bash <(curl -sL https://raw.githubusercontent.com/dodosea1/telegram-assign-bot/main/android/install.sh)

    1~5분 걸리고 글자가 많이 지나가도 정상입니다. ✅ 설치 완료가 나오면 끝. 중간에 질문이 나오면 엔터.

  6. 텔레그램 로그인

    tele login
    • api_id → api_hash → 전화번호(+821012345678 형식) → 텔레그램으로 온 코드
    • 2단계 인증 비밀번호를 쓰고 있으면 그것도 묻습니다
    • ✅ 로그인 완료가 나오면 성공

  7. 홈 화면 버튼 만들기

    • 홈 화면 빈 곳 길게 누르기 → 위젯 → Termux:Widget 끌어다 놓기
    • 버튼 3개: 1 자동응답 켜기 · 2 자동응답 끄기 · 3 상태 보기

  8. 켜서 확인

    • 1 자동응답 켜기 누르기
    • 텔레그램 ‘저장한 메시지’에 🟢 자동응답 켜짐 (폰) 이 오면 설치 끝
    • 저장한 메시지에 /도움말 을 보내 명령어 목록 확인

처음 한 번: 담당자 등록

모든 명령은 텔레그램 ‘저장한 메시지’에 보냅니다. 다른 대화방에 보내면 상대에게 그대로 전송됩니다.

담당자 추가 — 이름 | 단톡방 제목 일부 | 주소

/담당자추가 박 | 오후조 | 서울시 ○○구 ○○로 1

‘박’은 단톡방에서 그 담당자 이름에 들어간 글자, ‘오후조’는 실제 단톡방 제목의 일부. 못 찾으면 목록을 보여 주니 골라서 다시 보내세요. 주소는 여러 줄도 됩니다.

안내 문구 — 예약 확정 때 대상에게 갈 말

/안내문구 박 | {대상}님, {담당자} 담당자로 예약 확정되었습니다.

{대상} {담당자} 는 글자 그대로 쓰면 보낼 때 실제 이름으로 바뀝니다.

문제 해결

켜기를 눌렀는데 🟢 알림이 안 와요

3 상태 보기를 누르세요. ‘로그인이 필요합니다’가 보이면 Termux 에서 tele login 을 다시 하세요. ‘연결이 끊겨 … 다시 연결’이 반복되면 와이파이 · 데이터를 확인하세요. 연결되면 저절로 다시 붙습니다.

한참 뒤에 보니 꺼져 있어요

절전 때문입니다. 설치 3단계(배터리 제한 없음)를 다시 확인하고, 최근 앱 목록에서 Termux 를 밀어서 지우지 마세요. 안드로이드 12 이상에서 계속 꺼지면: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 눌러 개발자 옵션을 켠 뒤, 개발자 옵션의 하위 프로세스 제한 사용 안 함(기종에 따라 이름이 조금 다름)을 켜세요.

홈 화면 버튼을 눌러도 아무 일이 없어요

Termux 와 Termux:Widget 을 둘 다 F-Droid 에서 받았는지 확인하세요. Termux 의 다른 앱 위에 표시 권한도 필요합니다. 그래도 안 되면 Termux 를 열고 tele start 를 입력해도 똑같이 켜집니다.

안내가 두 번씩 나가요

같은 계정이 PC 와 폰에서 동시에 켜져 있습니다. 한 곳을 끄세요. 켤 때마다 🟢 알림에 어느 기기인지 (PC) / (폰) 이 표시됩니다.

새 버전으로 바꾸고 싶어요

끄기 버튼으로 끈 다음 Termux 에서 입력하세요. 로그인 · 담당자 · 문구는 그대로 남습니다.

tele update
Termux 에서 쓸 수 있는 명령

tele start 켜기 · tele stop 끄기 · tele status 상태 · tele log 기록 실시간 보기(나가기: 볼륨 아래 + C) · tele login 다시 로그인 · tele update 새 버전

꼭 지킬 것

  • 같은 계정을 PC 와 폰에서 동시에 켜지 않기
  • 명령은 ‘저장한 메시지’에서만
  • api_hash · 로그인 코드 · 2단계 비밀번호는 아무에게도 알려 주지 않기 (이 프로그램을 만든 사람에게도)
  • 폰을 바꾸거나 남에게 줄 때는 Termux 앱을 삭제하고, 텔레그램 → 설정 → 기기에서 그 세션을 종료
  • 실전 전에는 나 + 지인 한 명만 있는 테스트 단톡방으로 먼저 해 보기
폰 하나로 쓰는 안드로이드용 설명서입니다. 화면 설명은 삼성 갤럭시 기준이라 기종에 따라 메뉴 이름이 조금 다를 수 있습니다.
