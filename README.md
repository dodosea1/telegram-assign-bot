# 텔레그램 키워드 자동 안내

내 개인 계정으로 들어온 **1:1 메시지**에 등록한 키워드가 보이면 안내 문구를 자동으로 보냅니다.
키워드와 안내 문구는 텔레그램 **'저장한 메시지'** 방에 명령을 보내서 관리합니다.

## 1. 준비 (한 번만)

1. **파이썬 설치** — https://www.python.org/downloads/ (Windows는 설치 화면에서 "Add python.exe to PATH" 체크)
2. **텔레그램 API 값 발급**
   - https://my.telegram.org 접속 → 전화번호로 로그인
   - "API development tools" → 앱 이름 아무거나 입력 후 생성
   - 화면에 나오는 `api_id`(숫자)와 `api_hash`(영문·숫자)를 메모

## 2. PC에서 실행

Windows: `start.bat` 더블클릭
그 외: 터미널에서

```
pip install -r requirements.txt
python telegram_autoreply.py
```

처음 한 번은 `api_id`, `api_hash`, 전화번호, 텔레그램 앱으로 오는 로그인 코드(2단계 인증을 쓰면 비밀번호도)를 물어봅니다. 그다음부터는 바로 시작됩니다.
창을 닫거나 PC가 꺼지면 자동 안내도 멈춥니다.

## 3. 키워드 관리 (텔레그램 '저장한 메시지'에서)

| 명령 | 설명 |
|---|---|
| `/추가 배송, 택배 \| 배송은 결제 후 2~3일 걸립니다.` | 키워드(쉼표로 여러 개) + 안내 문구 등록. 문구는 여러 줄 가능 |
| `/목록` | 등록된 안내와 번호 보기 |
| `/보기 1` | 1번 안내 문구 전체 보기 |
| `/수정 1 \| 새 안내 문구` | 1번 문구 바꾸기 |
| `/키워드 1 \| 배송, 택배, 운송장` | 1번 키워드 바꾸기 |
| `/삭제 1` | 1번 삭제 |
| `/끄기` / `/켜기` | 자동 발송 일시 중지 / 재개 |
| `/간격 10` | 같은 사람에게 같은 안내를 다시 보내지 않는 시간(분). `0`이면 제한 없음 |
| `/상태` | 현재 설정 확인 |
| `/도움말` | 명령어 목록 |

폰의 텔레그램 앱에서 '저장한 메시지'에 보내도 똑같이 동작합니다.

## 3-1. 예약 확정 → 완성 → 준비 확인 → 주소 전달

1~4단계(대상 문의, 단톡방에서 가능 시간 확인, 시간 통보, 다른 담당자 추천)는 지금처럼 직접 대화합니다.
대상이 예약을 확정한 뒤부터 프로그램이 돕습니다. **내가 할 일은 `/확정`과 `/완성` 두 줄**입니다.

5. (나) 저장한 메시지에 `/확정 홍길동 박` → (자동) 박의 안내 문구가 홍길동에게 나감
6. (자동) 홍길동이 "완성"이 들어간 말을 하면 저장한 메시지로 📦 알림 (원문 포함, 단톡방에는 아직 안 감)
   → (나) 직접 확인하고 `/완성 홍길동` → (자동) 박 단톡방에 준비 확인요청이 올라감
7. (박) 단톡방에 "확인" / "올려주세요" (요청 메시지에 답장해도 되고 그냥 써도 됨) → (자동) 홍길동에게 박의 주소 발송, 단톡방에 `#1 주소 전달 완료` 답장, 나에게 알림

`/자동요청 켜기`를 보내면 6단계도 자동이 됩니다(완성 알림을 알아들으면 `/완성` 없이 바로 단톡방에 요청). 기본은 꺼짐입니다.

처음 한 번 준비:

| 명령 | 설명 |
|---|---|
| `/담당자추가 박 \| 박 단톡방 이름 \| 주소` | 단톡방 이름은 일부만 써도 됨. 단톡방 멤버 중 이름에 '박'이 들어간 사람을 담당자로 잡음. 못 찾으면 멤버 목록을 보여 줌 → `/담당자추가 박 \| 단톡방 \| @아이디 \| 주소` |
| `/안내문구 박 \| 문구` | 예약 확정 때 대상에게 보낼 박 전용 문구. `{대상}` `{담당자}`는 이름으로 바뀜 |
| `/요청문구 문구` | 단톡방 준비 확인요청 문구. `{번호}` `{대상}` `{담당자}` 사용. `{번호}`를 안 넣으면 앞에 `[#번호]`가 자동으로 붙음. `/요청문구 기본`이면 처음 문구 |
| `/완성단어 완성, 완료, 다됐어요` | 대상이 이 말을 하면 📦 알림을 보냄 (쉼표로 구분). 기본값: 완성 |
| `/자동요청 켜기` · `/자동요청 끄기` | 6단계 자동 여부. 기본: 꺼짐 (알림만, 요청은 `/완성`으로) |
| `/확인단어 확인, 올려, ㅇㅋ` | 담당자가 쓰면 준비됨으로 볼 말. 기본값: 확인, 올려 |
| `/담당자목록` · `/담당자보기 박` · `/담당자주소 박 \| 새 주소` · `/담당자삭제 박` | 담당자 관리 |

문구·단어 명령은 뒤에 아무것도 안 쓰고 보내면(`/요청문구`, `/완성단어`, `/확인단어`, `/담당자보기 박`) 지금 값을 보여 줍니다. 그걸 길게 눌러 복사하고, 고쳐서 다시 보내면 편집됩니다. '기본'을 붙이면 처음 값으로 돌아갑니다.

진행 중:

| 명령 | 설명 |
|---|---|
| `/확정 홍길동 박` | 예약 확정. 대상 이름은 1:1 대화방에 보이는 이름. 다른 담당자로 다시 `/확정`하면 변경됨 (이미 요청이 올라갔으면 새 담당자 단톡방으로 다시 요청) |
| `/완성 홍길동` (또는 `/완성 3`) | 완성을 직접 확인한 뒤 담당자 단톡방에 준비 확인요청을 올림 |
| `/대기` · `/재요청 3` · `/취소 3` | 진행 중 건 보기 / 요청 다시 올리기 / 취소 |
| `/전달 3` | 담당자 확인이 애매해서 자동으로 안 보낸 건의 주소를 직접 보냄 |

자동 처리 규칙:
- 담당자 한 명이 여러 건의 예약을 동시에 가질 수 있습니다.
- 📦 알림에는 "(완성 알림으로 보입니다)" / "(완성 전 말일 수도 있습니다)" 같은 참고 표시가 붙지만, 단톡방 요청 여부는 항상 내가 `/완성`으로 정합니다.
- 확정 없이 완성 관련 말이 오면 "`/확정` 한 뒤 `/완성`" 하라고 알려 줍니다.
- 이미 요청이 올라간 건에서 대상이 또 "완성"이라고 해도 알림을 보내지 않습니다.
- 단톡방에서는 **등록된 담당자 본인이** 보낸 것만 인정합니다. 다른 배정자가 "확인"해도 무시합니다.
- 답장 없이 "확인"만 와도 처리합니다. 단, 아래 경우는 자동으로 보내지 않고 나에게 알립니다 → 맞으면 `/전달 번호`
  - 내 요청 이후 다른 사람(다른 배정자 등)이 단톡방에 말한 경우 (그 사람 건에 대한 확인일 수 있음)
  - 그 담당자에게 확인대기 건이 여러 개인데 `#번호`나 대상 이름이 없는 경우
- 담당자가 내 요청이 아닌 다른 메시지에 답장으로 "확인"한 것은 다른 배정자 건으로 보고 무시합니다.
- "나중에 올려주세요", "확인 아직 못했어요"처럼 부정하는 말이 섞이면 준비로 치지 않습니다. "반려"가 들어간 답장은 나에게 알리기만 합니다.
- 주소는 한 건에 한 번만 나갑니다.

건과 담당자 기록은 `automation.db`에 저장되므로 프로그램을 다시 켜도 그대로 이어집니다.

### 텔레그램 없이 시험해 보기

```
python simulator/sim_server.py
```
브라우저에서 http://127.0.0.1:8765 를 엽니다. '✏️ 문구 편집'에서 정한 문구·단어는 같은 창 맨 아래 '📋 실제 텔레그램에 옮기기'에 명령으로 나오니, 하나씩 복사해 실제 '저장한 메시지'에 보내면 됩니다. (시뮬레이터와 실제 봇의 설정은 서로 따로 저장됩니다) 같은 코드가 가짜 텔레그램 위에서 돌아가며, 대상·담당자·다른 배정자 역할을 바꿔 가며 메시지를 보내 볼 수 있습니다. 데이터는 `simulator/data/`에만 저장되고, 다시 켜도 지난 상태가 이어집니다. 지우려면 화면의 '처음부터 다시'를 누르거나 `--fresh`를 붙여 켭니다.

## 4. 동작 규칙

- 다른 사람이 보낸 **1:1 메시지에만** 반응합니다. 그룹·채널·봇·내가 보낸 메시지는 무시합니다.
- 띄어쓰기와 영문 대소문자는 무시하고 찾습니다. (`배송 조회`로 등록 → `배송조회`에도 반응)
- 한 메시지에 여러 안내의 키워드가 있으면 해당 안내를 모두 보냅니다.
- 같은 사람에게 같은 안내는 기본 10분에 한 번만 보냅니다. (`/간격`으로 변경, 프로그램을 다시 켜면 초기화)
- 발송 기록은 `autoreply.log`에 남습니다.

## 5. 안드로이드 폰으로 옮기기 (Termux)

1. **Termux** 앱 설치 (F-Droid 또는 Termux 공식 GitHub 배포판)
2. Termux에서:
   ```
   pkg update && pkg install python
   pip install telethon
   termux-setup-storage
   ```
3. `telegram_autoreply.py`, `config.json`, `rules.json`을 폰으로 복사한 뒤 Termux에서 해당 폴더로 이동해 실행:
   ```
   termux-wake-lock
   python telegram_autoreply.py
   ```
   폰에서는 로그인 코드를 한 번 다시 입력합니다. (`autoreply.session`은 복사하지 않습니다)
4. 폰 설정에서 Termux의 **배터리 최적화를 해제**해야 화면이 꺼져도 계속 돕니다.

PC와 폰에서 **동시에 켜두면 안내가 두 번** 나갑니다. 한쪽만 켜 두세요.

## 주의

- `config.json`과 `autoreply.session`은 내 텔레그램 계정에 접속할 수 있는 정보입니다. 다른 사람에게 보내거나 공개 저장소에 올리지 마세요.
- 개인 계정 자동 발송은 텔레그램이 스팸으로 판단하면 계정이 제한될 수 있습니다. 이 프로그램은 먼저 온 메시지에만 답하고 재발송 간격을 두지만, 간격을 0으로 두고 많은 사람에게 같은 문구를 반복 발송하는 식의 사용은 피하세요.
